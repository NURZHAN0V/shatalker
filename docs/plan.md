# План реализации

Порядок работ **с нуля до готового результата**. Не прыгать через фазы. Тексты промптов для Cursor — в [prompts.md](./prompts.md). Стек и мир — в [idea.md](./idea.md).

**Готовый результат (клиент):** одна вылазка в Периметр, полный цикл заказа, автобой, фейковая рация, ~60 FPS, без сервера.

**Готовый результат (онлайн):** тот же клиент плюс аккаунт, сейв в Postgres, живая рация, люди на Насыпи. Бой по-прежнему на клиенте.

**Готовый результат (атмосфера):** тот же клиент после фазы 8: пасмурное небо, земля читается, редкий декор аномалий, в склады не проваливаешься. Без теней, bloom и Havok.

## Как закрывать шаг

После каждого шага, иначе шаг не засчитан:

1. `npm run build` без ошибок (клиент). Для сервера — `make build`.
2. Игра запускается. Для клиента — `npm run dev`.
3. FPS в GM не просел «в пол».
4. Пункты шага в `PLAYTEST.md` проходятся руками.
5. Коммит, если всё живое.

Правила агента скопировать в корневой `AGENTS.md` в фазе 0. Главный приоритет — [performance.md](./performance.md). Графика — [assets.md](./assets.md), до фазы 8 только примитивы.

Нельзя: настоящий онлайн до фазы 9, модели до фазы 8, Tailwind/AutoMigrate никогда. Тени, bloom, SSAO, SSR, плагинный Havok — не в фазах 0–12 и не в 13–15, пока шаг явно не просит и FPS не измерен. Дешёвые AABB-коллайдеры — только фаза 15.

## Фаза 7. Чтобы играть, не читая код

Промптов в `prompts.md` на это нет — просить отдельно, по одному пункту.

- Сохранение в `localStorage` (сейв шаталкера, заказ, инвентарь). Reset Save в GM.
- Кнопка **AUTO TEST**: Кефир → заказ → хряки → сдать → награда → строка результата.
- Окружение из примитивов: кубы «депо», трубы, столбы. `freezeWorldMatrix`. Без новых огней и частиц, если FPS не запасён.

**Готово, когда:** перезагрузл страницу — прогресс на месте; AUTO TEST проходит сам; Насыпь читается как лагерь, не как пустая плоскость.

## Фаза 9. HTTP API

Требования — [backend.md](./backend.md). Клиент фазы 6–7 обязан запускаться **без** сервера.

- `server/`: Gin, GORM, Postgres, JWT, bcrypt, `.env.example`.
- Makefile: `make migrate-up` (goose), `make serve` без миграций.
- `GET /health`, register/login, `/me`, `/save`, заказы, инвентарь, история рации.
- Клиент: `VITE_API_URL` пустой → `localStorage`. Заданный → заливка сейва раз в 5–10 с.

**Готово, когда:** `make migrate-up && make serve`, логин с КПК, сейв после вылазки поднимается на другом «заходе». Docker ещё нет.

## Фаза 15. Столкновения (не Havok)

Промпты: атмосфера, шаги 15.1–15.3. После 13 (14 желательна).

Не подключать `@babylonjs/havok` / physics engine. Нет ragdoll и обломков. Y — кинематика: посадка на `GROUND_Y`, Space — прыжок в клиенте (вне нумерации фаз, не симуляция Havok).

| Шаг | Что появляется |
| --- | --- |
| 15.1 | Кламп игрока, хряков и ботов к площадке `WORLD_SIZE`. Клик за край не ставит маркер (или ставит на ближайшую точку на земле). |
| 15.2 | Статичные AABB (или цилиндры) по корням Kenney и крупным примитивам. Капсула **скользит** вдоль, не застревает на шаге ходьбы. Конфиг коллайдеров в `src/data` (размеры вручную, не mesh-cooking каждый кадр). |
| 15.3 | Клик-мув: точка внутри коллайдера — ближайшая свободная на земле, не «идти в стену». WASD и Авто не телепортятся сквозь депо. Боты/хряки — тот же набор, без raycast на всех каждый кадр. GM **Show colliders** (полупрозрачные боксы). |

**Готово, когда:** обошёл склад — не внутри меша; клик по земле у стены ставит маркер снаружи; Авто и AUTO TEST по-прежнему проходят заказ; FPS не хуже 13/14.

Если AABB роняет кадры — меньше коллайдеров (только здания, не трубы). Havok — **не в этом плане**, только отдельной просьбой после зелёной 15 и запаса FPS.
