# Промпты для Cursor

Не просить сразу «сделай весь Периметр». Идти по [plan.md](./plan.md). Тексты шагов 1–12 — ниже, атмосфера (13–15) и финал вылазки (16–19) — в конце. После каждого шага: не ломать существующий код, обновить `PLAYTEST.md`.

В текстах игры и кода: **Ш.А.Т.А.Л.К.Е.Р.**, шаталкер, Периметр. Не использовать чужие торговые названия франшиз.

---

## Стартовый промпт

```text
Создай браузерную 3D-игру на Vite + TypeScript + React + Babylon.js + Zustand.

Название: Ш.А.Т.А.Л.К.Е.Р.
Цель: минимальный прототип вылазки в аномальную зону «Периметр», но пока без настоящего онлайна. Это одиночная игра с фейковыми шаталкерами и рацией. Жанр — литературная аномальная зона, не ремейк чужой франшизы.
Главный приоритет: стабильные ~60 FPS. Не добавлять физику, тени, постпроцесс. Не писать позицию в Zustand/React каждый кадр. Один Babylon Engine.

Требования:
1. Игра должна запускаться через npm run dev.
2. Использовать только примитивы Babylon.js, без внешних моделей и текстур.
   Стили UI — обычный CSS, без Tailwind и UI-китов.
3. Игрок — оливковая капсула (шаталкер «Новичок»).
4. Земля — большая плоскость, цвет грязной земли / бетона.
5. Небо — пасмурное, зеленовато-серое. Добавить туман.
6. Камера — третье лицо, следует за игроком.
7. Управление:
   - WASD — движение;
   - мышь — вращение камеры;
   - клик по земле — идти в точку.
8. Состояние игрока хранить в Zustand:
   - name;
   - level (ранг);
   - hp;
   - maxHp;
   - mp (выносливость);
   - maxMp;
   - exp;
   - expToNext;
   - attack;
   - position.
9. Добавить простой React HUD поверх канваса в стиле грязного КПК (олива, ржавчина, тусклый жёлтый):
   - имя шаталкера;
   - ранг;
   - HP бар;
   - бар выносливости;
   - EXP бар.
10. Добавить кнопку Debug/GM panel («Консоль Периметра»):
   - Heal;
   - Level Up;
   - Teleport Forward;
   - Spawn Monster;
   - Show FPS (включить по умолчанию).
11. Добавить мутанта «Хряк»:
   - ржаво-красная капсула;
   - имя над головой;
   - полоска HP;
   - стоит на месте;
   - при атаке игрока получает урон.
12. Атака:
   - клавиша 1;
   - если цель рядом, нанести урон;
   - показать всплывающую цифру урона.
13. Если хряк умирает:
   - исчезает;
   - игрок получает опыт;
   - появляется сообщение в логе.
14. Создать файл PLAYTEST.md с шагами проверки.
15. Код должен быть запускаемым, без недостающих файлов и без внешних ассетов.
16. В текстах UI не использовать чужие торговые названия франшиз. Только Ш.А.Т.А.Л.К.Е.Р., шаталкер, Периметр, хряк, Барыга Кефир.
```

После любой фичи, если нужно проверить сборку:

```text
Run npm run build and fix all TypeScript/build errors.
```

Коммит (только если игра запускается и фича работает):

```text
If the game runs and the feature works, commit with message "feat: …".
```

## Шаг 3. Бой

```text
Добавь простой таб-таргет бой.
Клавиша 1 атакует текущую цель, если цель в радиусе 2.5.
Атака имеет кулдаун 1 секунду.
Наносимый урон равен атаке игрока плюс случайное значение от -2 до +2.
Показывать всплывающий урон над мутантом.
Хряк должен отвечать игроку, если игрок рядом.
Когда HP мутанта равно 0, мутант умирает и даёт опыт.
Добавить лог боя в UI.
```

## Шаг 4. Опыт и ранг

```text
Добавь систему опыта и ранга шаталкера.

Если опыт достигает expToNext, ранг повышается.
При повышении ранга:
- увеличить maxHp на 20;
- увеличить maxMp на 10;
- увеличить attack на 2;
- полностью восстановить HP и выносливость;
- показать текст "Ранг повышен".
Добавить кнопку в GM-панель: +1000 exp.
```

