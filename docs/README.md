# Документы

**Ш.А.Т.А.Л.К.Е.Р.** — браузерный одиночный прототип с фейковым онлайном: литературный жанр аномальной зоны, обёртка как у дешёвой онлайн-игры.

Порядок работ с нуля — [plan.md](./plan.md).

Не настоящее MMO и не ремейк чужой франшизы. Слово-ориентир в документах и в игре не используем: только **Ш.А.Т.А.Л.К.Е.Р.**, **шаталкер**, **Периметр**.
